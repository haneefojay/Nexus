# API Handbook

The API is a versioned, tenant-scoped JSON contract served by the NestJS/Fastify application. OpenAPI is generated at `/openapi.json`; interactive local documentation is at `/openapi`.

Read [conventions](./conventions.md), [errors](./errors.md), [pagination](./pagination.md), [idempotency](./idempotency.md), and [authorization](./authorization.md) before adding an endpoint. Domain requirements are indexed in the [traceability matrix](../traceability/requirements-matrix.md).
