# Definition of Done

## Requirement DoD

A requirement is done only when implementation and failure behavior match the catalogue; authorization/tenant/state rules are enforced; mapped automated tests pass; docs/OpenAPI/migrations are updated; observability exists; and no unresolved critical defect or misleading claim remains.

## Phase DoD

Every phase checklist item and requirement mapped to the phase is done; CI and phase-specific E2E/security/performance/accessibility gates pass; migrations are rehearsed; changelog/roadmap/traceability are current; no later phase was used to mask missing scope; and a phase report records evidence and warnings.

## MVP DoD

Phases 0–6 are complete; a representative organization completes the inspection-to-verification journey online and under offline conditions; tenant isolation and file security are independently reviewed; backup restore and deployment rollback are exercised; monitoring/runbooks are operational; and marketing/product language reflects only implemented behavior.

## Evidence

A checked box is not evidence. Link the requirement to tests, CI run, review, migration, report, or measured result. Waivers require owner, rationale, risk, expiry, and follow-up.
