# Target Users

## Initial customer profile

Small-to-mid-sized distributed power and energy O&M organizations with multiple physical sites, repeat inspection obligations, field connectivity constraints, and a need for evidence-backed remediation.

## Roles

| Role                         | Primary responsibility                   | Core need                                   |
| ---------------------------- | ---------------------------------------- | ------------------------------------------- |
| Organization Owner           | Tenant setup, members, policy            | Controlled access and accountability        |
| Operations Manager           | Inventory, plans, assignments, oversight | Current coverage and attention picture      |
| Field Technician / Inspector | Execute assigned work                    | Fast, offline-capable structured capture    |
| Supervisor / Reviewer        | Review and verify work                   | Evidence, history, and explicit transitions |
| Viewer                       | Read-only oversight                      | Trustworthy operational visibility          |

Roles are fixed in MVP. Permissions are enforced server-side and scoped to an active organization membership.
