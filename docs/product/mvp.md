# MVP

## Included

- Email/password authentication, sessions, password reset, organization membership, and fixed roles
- Site, asset type, asset, hierarchy, map, search, and CSV import
- Versioned inspection templates, recurring plans, runs, assignment, structured execution, and review
- Findings, corrective actions, evidence, verification, notifications, and immutable activity history
- Mobile-first PWA field mode with assigned-work caching, local command queue, sync, and offline photos
- Deterministic dashboard/attention states, PDF inspection reports, and CSV exports

## Excluded

Live telemetry, predictive maintenance, AI diagnosis, native mobile apps, route optimization, inventory/spares, billing, SSO/SCIM, arbitrary workflow builders, and a general work-order system. See [Out of Scope](./out-of-scope.md).

## Release test

A real organization can onboard assets, schedule and execute an inspection under intermittent connectivity, raise a finding, complete and verify corrective action, and retrieve an auditable report without fabricated data or cross-tenant exposure.
