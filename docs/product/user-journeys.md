# User Journeys

## 1. Organization activation

Owner verifies an account, creates an organization and timezone, invites members, and assigns fixed roles. Failure leaves no partial membership and reveals no account existence.

## 2. Inventory onboarding

Manager creates sites and asset types, imports or enters assets, resolves row errors, and verifies the map. Re-running an import is idempotent.

## 3. Inspection planning

Manager authors a template, publishes an immutable version, selects active targets, defines a recurrence in organization time, and assigns generated runs.

## 4. Field execution

Technician downloads assigned work, completes validated responses and evidence online or offline, sees truthful sync state, and submits once. A second device cannot concurrently own execution.

## 5. Remediation and verification

A finding creates at most one MVP corrective action. The assignee documents completion; an authorized reviewer verifies evidence before critical closure.

## 6. Oversight and reporting

Manager filters the map and attention queues, reviews coverage, opens immutable history, requests a report, and downloads it through an authorized short-lived URL.
