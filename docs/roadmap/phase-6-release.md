# Phase 6 — Release

## Goal

Validate and release the complete NEXUS MVP.

## Scope

- Release candidate
- Full unit, integration, E2E, security, tenant, offline, mobile, upload, report, load, and restore validation
- Production deployment and monitoring
- Demo environment and final documentation
- Release, rollback, and incident checklists

## Dependencies

All previous phase Definitions of Done.

## Definition of Done

- [ ] Production build, types, lint, tests, and migrations pass.
- [ ] Tenant, role, attachment, and offline security gates pass.
- [ ] Offline inspection E2E passes.
- [ ] Backup restore and rollback procedures are verified.
- [ ] Production deployment and observability work.
- [ ] No blocking defects or fake product capability remain.
- [ ] Final engineering report documents implementation and deferrals.
