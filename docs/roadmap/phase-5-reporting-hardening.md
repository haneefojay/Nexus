# Phase 5 — Reporting & Hardening

## Goal

Make the MVP operationally deployable, measurable, accessible, and resilient.

## Scope

- Asynchronous inspection PDF reports and CSV exports
- Dashboard refinement from real calculations
- WCAG 2.2 AA review
- Structured logs, tracing, error monitoring, alerts, health/readiness
- Rate limiting, upload/security hardening, dependency review
- Performance/load tests, backup/restore, deployment and seeded demo

## Dependencies

Completed domain lifecycle and production-like infrastructure.

## Tests

Report truth and immutability, accessibility, security suite, 10k-asset map/search loads, 100k-row import, backup restore, and production smoke tests.

## Definition of Done

- [ ] Real reports and exports can be generated and authorized.
- [ ] Accessibility and security blockers are resolved.
- [ ] Performance targets are measured.
- [ ] Errors, jobs, and infrastructure are observable.
- [ ] Backup/restore is verified.
- [ ] Fictional demo uses the real backend.
